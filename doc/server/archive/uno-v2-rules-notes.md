# UNO 第二版规则说明

## 目标

第一版已完成基础可玩闭环。第二版开始补齐功能牌的正式规则约束，尤其是 `+4 万能牌` 的合法出牌条件。

## 功能牌

第二版确认支持以下功能牌：

1. 禁止牌 / Skip
2. 反转牌 / Reverse
3. Draw Two / +2
4. 变色万能牌 / Wild
5. +4 万能牌 / Wild Draw Four

## Wild / 变色万能牌

规则：

- 玩家可以在合法出牌时打出 Wild。
- 打出后必须指定下一轮当前颜色：红 / 黄 / 绿 / 蓝。
- 后续玩家需要按指定颜色继续出牌，直到颜色再次被改变。

## Wild Draw Four / +4 万能牌

第二版新增 `+4` 质疑与合法性规则。

### 合法性

```text
只有当出牌者手中没有与当前参照颜色相同的牌时，+4 才是合法出牌。
```

这里的“同颜色牌”只看牌面颜色：

- 红 / 黄 / 绿 / 蓝 的数字牌算同颜色。
- 红 / 黄 / 绿 / 蓝 的功能牌也算同颜色。
- Wild / +4 万能牌不算同颜色牌。
- 同数字但不同颜色不算。
- 同功能但不同颜色不算。

示例：

```text
当前颜色 = 红
玩家手里有 红 7
=> 不能出 +4

当前颜色 = 红
玩家手里有 红 Skip
=> 不能出 +4

当前颜色 = 红
玩家手里只有 蓝 7 / 黄 Skip / Wild
=> 可以出 +4
```

### 质疑

`+4` 打出后，下家可以质疑出牌者手牌。

```text
质疑成功：出 +4 的玩家摸 4 张。
质疑失败：下家摸 4 张。
```

服务端已新增核心方法：

```cpp
ChallengeWildDrawFour(userid, now_ms)
```

当前先完成服务器规则能力，Web 入口后续再接。

## +2 / +4 无限叠加

第二版支持罚牌无限叠加，直到某位玩家没有可叠加牌为止。

叠加规则：

```text
+2 后面可以继续叠 +2 或 +4。
+4 后面只能继续叠 +4，不能叠 +2。
```

例子：

```text
A 出 +2
B 出 +2
C 出 +4
D 无 +4 可叠
=> D 摸 8 张，并跳过本回合
```

服务端使用累计罚牌数：

```cpp
draw_penalty_count_
last_draw_stack_type_
```

玩家无法继续叠加时，执行摸牌会一次性摸累计数量，并自动跳过回合。

## 普通摸牌规则

玩家无牌可出时：

```text
必须从公共牌库摸 1 张牌。
```

摸牌后：

```text
如果新摸的牌可以匹配出牌，玩家可以选择立即出牌或跳过回合。
如果新摸的牌仍无法匹配，直接结束回合。
```

当前服务端已有对应流程：普通 `DrawCard` 只摸 1 张；若可出则保留当前回合等待 `PlayCard` 或 `PassAfterDraw`；若不可出则自动 `AdvanceTurn`。

## 公共牌库耗尽

第二版规则：

```text
公共牌库剩余卡牌为 0 时，系统回收所有已打出的牌，保留最后一张弃牌作为参照牌，其余弃牌重新洗牌生成新的公共牌库，对局继续。
```

补充：

```text
单局洗牌重置次数无上限。
每次重置后卡牌随机重组。
如果弃牌堆也没有足够卡牌可回收，才按牌库耗尽结束局处理。
```

服务端已实现：

```cpp
RecycleDiscardPileIntoDrawPile()
DrawOne()
```
