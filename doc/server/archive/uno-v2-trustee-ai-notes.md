# UNO 第二版托管 AI 规则

## 目标

托管 AI 负责真人超时后的自动操作，也用于 debug 机器人玩家。

## 规则

### 1. 自动摸牌 / 智能出牌

- 无牌可出时自动摸牌。
- 有牌可出时智能出牌。
- 普通状态出牌优先级：

```text
数字牌 > 禁止牌 Skip > 反转牌 Reverse > Draw Two > 万能牌 Wild > +4 Wild Draw Four
```

说明：用户原始需求未单独列出 Draw Two 的普通优先级，服务端暂放在 Reverse 后、Wild 前。

罚牌叠加状态下优先遵守叠加规则：

```text
+2 链：可叠 +2 或 +4
+4 链：只能叠 +4
无可叠牌：摸累计罚牌并跳过
```

### 2. 手牌剩 1 张自动 UNO

托管 AI / 机器人手牌剩 1 张时视为自动 UNO 喊话，不触发漏喊惩罚。

服务端已实现 `UNO pending / declareUno / 漏喊罚 2 张` 状态机；机器人/托管玩家在剩 1 张牌时自动视为已喊 UNO。

### 3. 质疑 +4

托管 AI / 机器人面对 +4 质疑机会时，默认选择质疑。

服务端已在自动操作入口中处理：如果当前玩家是 +4 质疑者，优先执行：

```cpp
ChallengeWildDrawFour(userid, now_ms)
```

### 4. 特殊牌惩罚承接

托管 AI 正常承接罚牌连锁，不规避系统罚牌。

- 有可叠牌则按叠加规则出牌。
- 无可叠牌则摸累计罚牌并跳过回合。

### 5. 操作延时

托管 AI / 机器人操作延时为：

```text
2 到 6 秒
```

当前 debug table 使用伪随机延迟：

```cpp
RobotThinkDelayMs(userid, now_ms)
```

### 6. 结算

对局结束时应正常结算托管玩家的：

- 金币
- 积分
- 经验

当前这些玩家经济数据暂未接入，后续接真实结算数据时实现。

- +4 质疑默认选择质疑
