# UNO 108 张牌组成

当前服务端使用标准 UNO 108 张牌。

## 一、四色牌：100 张

颜色：

```text
红、黄、绿、蓝
```

每种颜色 25 张：

| 牌型 | 数量 |
|---|---:|
| 数字 0 | 1 |
| 数字 1～9 | 每个 2 张，共 18 张 |
| Skip 跳过 | 2 |
| Reverse 反转 | 2 |
| Draw Two +2 | 2 |
| 合计 | 25 |

四色合计：

```text
25 × 4 = 100 张
```

## 二、万能牌：8 张

| 牌型 | 数量 |
|---|---:|
| Wild 万能变色牌 | 4 |
| Wild Draw Four 万能 +4 牌 | 4 |
| 合计 | 8 |
```

## 三、总数

```text
100 + 8 = 108 张
```

## 四、当前代码中的牌 ID 顺序

```text
红色：1～25
黄色：26～50
绿色：51～75
蓝色：76～100
万能牌：101、103、105、107
万能 +4：102、104、106、108
```

每种颜色的生成顺序为：

```text
0
1、1
2、2
...
9、9
Skip、Skip
Reverse、Reverse
+2、+2
```

## 五、首张弃牌规则

牌堆洗牌后，首张弃牌必须是数字牌。

如果抽到功能牌或万能牌，则放回牌堆底部，继续抽取，直到抽到数字牌。

因此：

```text
首张弃牌一定是数字牌
首位玩家再从四名玩家中随机选择
```
