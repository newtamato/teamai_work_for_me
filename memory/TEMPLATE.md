# 主题

- 类型：用户偏好 / 项目事实 / 设计决策 / 工程经验
- 状态：active / pending / superseded / revoked（选择一个）
- 创建日期：YYYY-MM-DD（北京时间）
- 更新日期：YYYY-MM-DD（北京时间）
- 适用范围：
- 关键词：
- 来源：用户指令日期、项目文件章节或可核实的提交/证据
- 验证方式：user-reported / code-verified / test-verified / document-derived
- 最近核实日期：YYYY-MM-DD，未核实填“未核实”
- 替代关系：无，或旧/新条目的相对链接

## 内容

一个主题的简短事实或约定；明确条件和限制。不填入敏感业务数据。

## 证据与定位

可复查的项目相对链接及验证摘要；未核实的部分明确标注。

## 下次行动

下次遇到相同触发条件时应执行的具体动作；不覆盖权威规则或用户最新指令。

## 失效条件

哪些变化需要重新核实、降为 pending 或被新条目替代。

## 变更记录

- YYYY-MM-DD：新增；写入触发为用户明确要求 / 自动记录，说明依据。
